# Agry-Key: Fake, Sample, and Placeholder Data Inventory

This inventory documents all fake data, hardcoded fallbacks, synthetic calculations, mock generators, and unverified assumptions identified across the Agry-Key codebase during the Phase 0 audit and tracks remediation status across phases.

---

## Status Legend
- **REMOVED**: Fabricated or mock data has been completely eliminated from production paths.
- **SOURCED**: Replaced with verified observations carrying source, date, location, and freshness.
- **REMEDIATED**: Architectural assumption or misleading label replaced with truthful typed state and user control.
- **TEST-ONLY**: Permitted only in isolated unit/integration test fixtures.
